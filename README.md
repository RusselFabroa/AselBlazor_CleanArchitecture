# 🚀 AselDev Blazor Clean Architecture

A production-grade **Blazor .NET 8** application built using **Clean
Architecture principles** --- designed for scalability, maintainability,
and enterprise use.

------------------------------------------------------------------------

## 📌 Overview

**AselDev** is a modern enterprise-ready web application that
demonstrates:

-   Clear separation of concerns
-   Scalable architecture
-   Maintainable codebase
-   Real-world enterprise patterns

> Built with performance, structure, and long-term maintainability in
> mind.

------------------------------------------------------------------------

## 🧱 Architecture

### 🟢 Domain (`AselDevBlazor.Domain`)

Core business logic, entities, and domain rules.

### 🟣 Application (`AselDevBlazor.Application`)

Use cases, DTOs, interfaces, and business workflows.

### 🟠 Infrastructure (`AselDevBlazor.Infrastructure`)

Database, Identity, logging, and external services.

### 🔵 Web (`AselDevBlazor.Web`)

Blazor UI, controllers, and application entry point.
